# AI Pro Tips

I trucchi che usi davvero con le AI, raccolti da chi le usa tutti i giorni. Un tip per file, scritto in due minuti, in italiano.

Niente guide da 40 pagine: solo cose concrete che ti cambiano il risultato.

## ➕ [Aggiungi il tuo tip](https://github.com/brankss/ai-pro-tips/new/main/tips?filename=tuo-tip.md&value=---%0Atitolo%3A%20Scrivi%20qui%20il%20tip%20in%20una%20frase%0Atool%3A%20Qualsiasi%0Acategoria%3A%20prompt%0Aautore%3A%20tuo-username%0A---%0A%0ASpiega%20qui%20il%20tip%3A%20cosa%20fare%2C%20quando%20serve%20e%2C%20se%20puoi%2C%20un%20esempio.%0A%0A%28categorie%20possibili%3A%20prompt%2C%20coding%2C%20studio%2C%20immagini-video%2C%20automazione%2C%20altro%29%0A)

Ti serve solo un account GitHub. Clicca il link qui sopra, poi:

1. Cambia il nome del file (in alto) con un nome tuo, tipo `fatti-fare-le-domande.md`
2. Compila i campi e scrivi il tip
3. Premi **Commit changes**, poi **Propose changes**
4. Premi **Create pull request**

Fine. Un controllo automatico ti dice se manca qualcosa. Dettagli in [CONTRIBUTING.md](CONTRIBUTING.md).

## Come funziona

```

```
